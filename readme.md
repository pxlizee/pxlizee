### 📌 Profile Summary

Mahasiswa Teknik Informatika dengan minat mendalam pada pengembangan perangkat lunak terintegrasi—mulai dari antarmuka aplikasi web/mobile, sistem backend, hingga interaksi perangkat keras (embedded systems/IoT). Berfokus pada penulisan kode yang terstruktur, efisien, dan solusi teknologi yang fungsional.

- 💻 **Software & Mobile Development:** Mengembangkan aplikasi lintas platform menggunakan React Native, TypeScript, Java, serta backend berbasis Python dan Node.js.
- 🔌 **Embedded Systems & IoT:** Merancang prototipe sirkuit mikrokontroler, integrasi sensor cerdas, dan sistem monitoring otomatis.
- 📊 **Data & Computational Systems:** Mengimplementasikan logika komputasi, metode numerik, sistem inferensi fuzzy, serta manajemen basis data terstruktur (SQL & NoSQL).
- 🚀 **Continuous Learning:** Terus mengeksplorasi arsitektur perangkat lunak modern dan optimalisasi performa sistem.
